Mən öyrənirəm — версия 2.0

Файлы:
- index.html — структура страницы
- styles.css — оформление и адаптация
- script.js — логика обучения
- words-lesson-1.json — слова первого урока в формате JSON

Как запустить:
1. Распакуйте архив в отдельную папку.
2. Откройте index.html в современном браузере.
3. Для более надёжного запуска можно открыть папку через локальный сервер или разместить её на GitHub Pages / Vercel.

Важно:
- Прогресс сохраняется в localStorage конкретного браузера и устройства.
- Сделайте резервную копию, прежде чем очищать данные браузера.
- Озвучивание зависит от голосов, установленных в браузере/устройстве.
- Слова и транскрипции перенесены из присланных фотографий; транскрипцию можно редактировать при добавлении новых слов.
